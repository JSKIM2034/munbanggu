# 문방구 퇴마단

90년대 동네 꼬마들이 문방구 장난감으로 학교 귀신을 물리치는 귀여운 액션 로그라이트예요. (Godot 4.4, 웹/모바일)

- 플레이: https://jskim2034.github.io/munbanggu/
- 조작: 화면 아무 데나 누르고 끌면 조이스틱. 공격은 자동이에요. (PC는 WASD/방향키)

## 게임 구조
- 한 판: 장소 6곳(운동장, 학교 복도, 밤의 과학실, 화장실, 옥상, 음악실) x 학년(1~6) 골라 출발, 4:00에 보스. 보스를 물리치면 클리어
- 특별한 날(날짜마다): 비 오는 날, 운동회 날, 시험 기간, 방학
- 판 이벤트: 급식 시간(하트), 쉬는 시간 종(귀신 도망), 선생님 숙제 검사(미니 미션 → 보물 상자), 부서지는 화분과 소화기
- 장소가 바뀔수록 어려워져요(장소마다 +8단계). 앞 장소를 10단계까지 깨야 다음 장소가 열려요
- 단계마다 날씨가 바뀌어요: 바깥은 맑음/노을/비/밤/눈/천둥 번개, 학교 안은 청소 시간/정전/비상벨/창밖 천둥/한밤의 학교
- 보조 아이템도 눈에 보여요: 물 뿌리기, 도는 공책 종이, 시계 느리게 하기, 반짝 발자국, 돋보기 햇빛, 줍는 범위 원, 명찰 하트 방패
- 효과음은 tools/make_sfx.py로 만든 소리예요(겹친 소리와 잔향)
- 보스는 단계마다 다른 모습으로 나오고, 높은 단계에선 화난/얼음/그림자/황금/전설의 보스로 바뀌어요. 등급마다 회오리, 십자 줄기, 점프 내려찍기, 동전 비, 고리 연타 공격이 더해져요
- 주간 도전: 주마다 같은 장소, 친구, 날씨로 점수 경쟁, 결과 복사
- 판 안: 메인 4종(물총, 딱지, 요요, 고무줄) + 보조 6종, 세트 진화, 정예 귀신의 보물 상자, 다시 뽑기, 부활
- 판 밖: 동전으로 문방구 영구 강화(무기별 강화 포함), 친구 4명 해금, 도장(업적), 오늘의 숙제, 귀신 도감

## 폴더
- `source/` Godot 프로젝트 (`main.gd` 한 판, `menu.gd` 메뉴, `save.gd` 저장과 메타 데이터)
- `tools/` 모델 리깅(`rig_kid.py`), 웹 내보내기(`build_web.py`)
- 맨 위 `index.*` 파일들은 웹 배포본이에요.

글꼴: 주아체 (SIL OFL, `source/fonts/OFL.txt`)
