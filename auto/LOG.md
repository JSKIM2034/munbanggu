# 자동 개선 기록

새벽 자동 작업이 매번 맨 위에 기록을 추가해요.

## 2026-11-23 (월) 추가 5 (사용자: "숙제 동그라미가 너무 단색, 볼륨감/높이")
- 숙제 검사 동그라미를 살짝 솟은 무대로: 옆면 있는 낮은 원통(높이 0.16) + 윗면 무늬(가운데 밝고 가장자리 진함, 퍼지는 물결, 도는 점선 고리) + 하얀 테두리 + 위로 옅어지는 빛 기둥
- 안에 있으면 옆면/테두리/빛 기둥이 초록, 윗면에 초록 부채꼴이 시계처럼 채워져서 얼마나 버텼는지 보임
- 처음 나올 때 멈칫하지 않게 판 시작할 때 땅 밑에서 한 번 그려 둠(_prewarm)
- 확인 화면: `--shot=mission`(밖), `--shot=mission_in`(안, /tmp/f_mission_in_*.png). 봇 4판 오류 0

## 2026-11-23 (월) 추가 4 (사용자: "후반에 소리가 겹쳐서 끊기는 것처럼 들려요")
- 원인: 효과음 자리가 10개뿐인데 후반엔 초당 약 60번 소리를 내려고 해서, 새 소리가 아직 울리는 소리(레벨업, 진화 같은 큰 소리 포함)를 계속 잘라 먹었음
- 고침: 자주 나는 소리(맞는 소리, 딱지 줍기, 물총 등)는 같은 소리끼리 최소 간격(45~150ms)을 두고, 자리가 모자라면 자주 나는 소리 자리만 빌림(큰 소리는 안 끊김). 자리 10 → 16개. 전체 소리 끝에 리미터를 달아 겹쳐도 찢어지지 않게
- 봇(운동장 1, 강화): 후반 30초 동안 낸 소리 약 1830번 → 380번(초당 약 13번), 나머지는 겹쳐서 건너뜀. 오류 0. 자동 플레이 줄 끝에 snd=낸/건너뛴 표시

## 2026-11-23 (월) 추가 3 (사용자: "1~2단계에서 귀신이 너무 늦게 나와")
- 원인: 귀신 수를 0.75배로 줄이면서 소수점이 버려져, 1단계 처음 약 27초 동안 귀신이 하나도 안 나왔음 (봇: 30초까지 처치 0)

- 봇: 1단계 처음 30초 처치 0 → 24 (예전 원래 게임과 같은 속도)

## 2026-11-23 (월) 추가 2 (사용자와 대화 중): 진화 비법 잠금 + 단계 차등
- 진화 비법: 고른 친구의 시작 무기 진화만 처음부터. 나머지 5개는 모든 장소의 깬 단계 합이 1/3/5/7/10이 되면 하나씩 열림 (운동장 10단계면 전부). 예전에 진화해 본 저장은 모두 열림(`evo_legacy`). 잠긴 건 레벨업 카드, 도감, 일시정지 세트표에 "잠김", 세트를 다 모았는데 잠겨 있으면 판 안에서 한 번 알림, 새로 열리면 결과 창에 "새 진화 비법"
- 단계 차등: 실제 난이도 1~10 구간만 순하게 시작 (1단계: 귀신 체력 x0.6, 귀신 수 x0.75, 보스 체력 x0.3 → 10단계에서 x1.0). 복도/과학실 이후는 그대로. 상수 `EASE_HP0/EASE_SPAWN0/EASE_BOSS0` (main.gd)
- 장소 카드에 다음 단계를 처음 깨면 열리는 것 표시: "깨면 열려요: 진화 비법 '…', 새 친구 …, 새 장소 …"
