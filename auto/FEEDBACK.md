# 사용자 요청과 플레이 소감

새벽 자동 작업이 가장 먼저 읽는 파일이에요. 해보고 느낀 점이나 바꾸고 싶은 점을 한 줄씩 적어 주세요.
(GitHub 웹에서 이 파일을 열고 연필 아이콘으로 고치거나, Claude에게 "피드백 파일에 적어줘"라고 하면 돼요.)

## 요청
- (2026-11-22) 사용자 PC(AMD Radeon Vega 8 내장 그래픽, 메모리 약 4GB급, Windows, Edge, itch.io에서 실행)에서 화면은 대체로 부드럽지만 가끔 툭 끊겨요. 언제 끊기는지는 특정이 어려워요. 처음 나오는 효과/귀신 준비(셰이더 컴파일), 메모리, 파티클 폭증 등 원인을 프레임 시간 기록으로 찾아서 줄여 주세요. 웹 빌드를 헤드리스 크롬으로 돌려 프레임 간격 50ms 넘는 순간을 기록하는 방식도 좋아요.
- (2026-11-22) 영어를 추가했어요(source/lang_en.gd). 새로 넣는 한국어 문장은 tr("...")로 감싸고 lang_en.gd에 영어도 같이 넣어 주세요. 데이터 표는 *_KO 상수에 쓰면 자동으로 번역돼요.
- (2026-11-22) 영어로 바꾸면 줄이 길어져서 단어가 잘리는 곳이 있어요. 영어 화면을 --shot 모드로 찍어 보고, 넘치는 글은 줄바꿈이나 글자 크기 자동 줄이기, 더 짧은 번역으로 고쳐 주세요.
